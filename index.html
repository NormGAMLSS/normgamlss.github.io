Architecture

Built for the real shape of your data

Seven of the things the package does, most shown with output from its own tutorial.

Model the full distribution
Location, scale, skew and kurtosis (μ, σ, ν, τ) fitted jointly as smooth functions of age, sex and site, not collapsed to a single mean trend.
Reference curves & outlier detection
Continuous, age-dependent centile bands plus an exact deviation (Z-)score per individual, so outliers are judged against a proper reference, not a fixed cutoff.
Permutation testing
Non-parametric p-values that test whether a covariate genuinely improves the fit, not just whether AIC happened to move.
Model comparison, mapped onto the brain
Run base-vs-target comparison across every parcel in parallel, then project the AIC differences straight onto a cortical surface.
Zero-shot site transfer
Recalibrate a reference model onto an entirely new scanner from a small calibration sample. The curves shift to the site without a full retrain.
Diagnostics after every fit
Residual and Q–Q checks, worm plots, and per-parameter summaries, so you can see whether the fitted distribution actually describes your data.
Share models, not data
Export a slim copy of a fitted model with no participant data in it. Anyone can use it for centiles and z-scores without the training data, with practically the same results. For a large cohort it is about 500× smaller and 10× faster.
Beyond the highlights. The package also handles data preprocessing and structuring, multiple-formula model comparison, evaluation metrics, continuous centiles with uncertainty, centile-position lookup, saving and reloading fitted models, transfer across several new sites at once, and parallel batch fitting with caching, each documented in full.
Example

Fit, predict, flag — in a few lines

The same workflow behind every figure on this page.

from normgamlss import Gamlss
from normgamlss.site_transfer_utils import site_transfer

# fit once: location, scale, skew and kurtosis jointly
model = Gamlss("m1", ["age", "sex", "site"], "thickness")
model.fit("model <- gamlss(y ~ pvc(age) + "
          "re(random=~1|as.factor(site)), family=SHASH())", train)
model.export_slim(train, "m1_slim.rds")  # no participant data in it

# share the slim model, no training data needed from here on
slim = Gamlss.load_model("m1_slim.rds")
z = slim.z_score(test, None)
slim.plot_centiles(test, None)

# adapt to a new scanner from 20 people, no retraining
adj = site_transfer("m1_slim.rds", None, new_data,
                    new_site="S7", selected_site="S1",
                    sample_size=20, y_val="thickness",
                    x_vals=["age", "sex", "site"])
