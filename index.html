Python package · built on R GAMLSS

Normative modeling that fits the whole distribution, not just the mean.

A Python package for normative modeling with GAMLSS. Fit a reference across age, sex and site, score new individuals against it, and transfer it to a new scanner from a handful of calibration subjects.

Workflow

From a dataframe to deviation scores in four steps

Each step is a Python call. The model itself is written in GAMLSS's own R formula syntax, so anything that works in gamlss() works here unchanged.

Deploy

Capabilities

Built for the real shape of neuroimaging data

Figures are tutorial output on synthetic data.

Model the full distribution

Location, scale, skew and kurtosis fitted jointly as smooth functions of age, sex and site, in any GAMLSS family.

Reference curves and deviation scores

Age-dependent centile bands with uncertainty, and a Z-score for every individual against the reference.

Permutation testing

Non-parametric p-values for whether a covariate improves the fit, from a permuted null of AIC differences.

Model comparison, mapped onto the brain

Compare formulas across every parcel in parallel and project the result onto a cortical surface.

Site transfer without retraining

Recalibrate a reference model onto a new scanner from a small calibration sample, one site or several at once.

Diagnostics after every fit

Residual and Q–Q panels, R's worm plots and convergence checks after every fit.

Share models, not data

Export a copy of a fitted model with no participant data in it. Anyone can compute centiles and Z-scores from it; for a large cohort it is about 500× smaller and 10× faster.

Example

Fit once. Score, share and transfer from there.

from normgamlss import Gamlss

model = Gamlss("m1", ["age", "sex", "site"], "thickness")
model.fit(r_code="""
model <- gamlss(y ~ pvc(age, by = as.factor(sex)) + re(random = ~1 | as.factor(site)),
                sigma.formula = ~ pvc(age),
                family = SHASH(), method = mixed(10, 100))
""", data=train)

model.plot_diagnostics()
model.evaluate(test, train, affected=test["affected"])
z = model.z_score(test, train)
c = model.centiles(test, train, centiles=[3, 10, 25, 50, 75, 90, 97])

model.plot_centiles(test, train, affected=test["affected"])
model.plot_z_scores(test, train, affected=test["affected"])
# a copy of the model with no participant data in it
model.export_slim(train, "m1_slim.rds")
slim = Gamlss.load_model("m1_slim.rds")
z = slim.z_score(new_subjects, None)

# recalibrate onto a new scanner from 20 healthy subjects
from normgamlss.site_transfer_utils import site_transfer
adj = site_transfer("m1_slim.rds", None, new_site_data,
                    new_site="S7", selected_site="S1", sample_size=20,
                    y_val="thickness", x_vals=["age", "sex", "site"])
