check_test_sites(train_data, test_data)

    Validates that your testing data ‘site’ column is a subset of the training data ‘site’ column. Displays extra sites and their sample distributions.

    Parameters:

        train_data : pandas.DataFrame
            DataFrame containing the training data with ‘site’ column

        test_data : pandas.DataFrame
            DataFrame containing the test data with ‘site’ column

    Returns:

        None : None
            Prints site distribution information and recommendations


Examples:

from normgamlss.utils import (
    add_extra_site_data,
    check_test_sites,
)

add_extra_site_data#

add_extra_site_data(train_data, test_data, fraction=0.2)

    Adds a fraction of healthy (‘None’) samples from extra sites in the test dataset to the training dataset to improve model performance on new sites.

    Parameters:

        train_data : pandas.DataFrame
            DataFrame containing the training data

        test_data : pandas.DataFrame
            DataFrame containing the test data

        fraction : float, default=0.2
            Fraction of ‘None’ samples to add from extra sites

    Returns:

        train_data : pandas.DataFrame
            Updated training dataset with added samples from extra sites

        test_data : pandas.DataFrame
            Updated test dataset with removed samples added to training


Examples:

train_data1, test_data1 = add_extra_site_data(train_data, test_data, fraction=0.2)

Extra sites found in the test set: ['HLMEG', 'KEMUB', 'ZSCPY']

# Sanity check: confirm the sites in test data are a superset of the sites in train data

remove_special_characters(dataframes)

    R library might give errors if your columns have special characters in their names, such as hyphens (“-“), ampersands (”&”), or spaces. This function replaces these special characters with underscores (“_”).

    Parameters:

        dataframes : list of pandas.DataFrame
            List of DataFrames to process

    Returns:

        modified_dfs : list of pandas.DataFrame
            List of DataFrames with modified column names

        name_maps : list of dict
            List of dictionaries mapping new column names to original names


Examples:

# For a single dataframe
[modified_df], [name_map] = remove_special_characters([df])
original_name = name_map['column_1_2']  # Returns 'column-1 & 2'

# For multiple dataframes
[modified_df1, modified_df2], [name_map1, name_map2] = remove_special_characters([df1, df2])
