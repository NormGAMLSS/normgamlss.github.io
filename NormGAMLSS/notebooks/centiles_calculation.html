Centiles Calculation#

gamlss_main.Gamlss.
centiles#

centiles(test_data, train_data, centiles=[3, 10, 25, 50, 75, 90, 97], func_name=None)

    Calculates specified centiles for each observation based on the fitted model parameters. Output shape is (number of samples, number of centiles).

    Parameters:

        test_data : pandas.DataFrame
            DataFrame containing the test data

        train_data : pandas.DataFrame
            DataFrame containing the training data

        centiles : list, default=[3, 10, 25, 50, 75, 90, 97]
            List of centiles to calculate, in percent: between 0 and 100, not 0 or 100 themselves (e.g. 2.5 or 97.5). If all values are below 1 (e.g. 0.03), a warning reminds you that the 3rd centile is 3

        func_name : str, optional
            Distribution family name. If None (default), the model’s own family is used; a different family raises an error

    Returns:

        centile_values : numpy.ndarray
            Array of shape (n_samples, n_centiles) with centile values


Examples:

# Centile calculation
centile_score = gamlss_model.centiles(df_test,df_train,func_name = 'SHASH', centiles = [3, 10, 25, 50, 75, 90, 97])
# Output is (n_samples, n_centiles)
print(f"Shape of centile scores: {centile_score.shape}")
print(centile_score)

gamlss_main.Gamlss.
create_site_adjusted_data#

create_site_adjusted_data(train_data, reference_site, correction_col_name='site',
                          model_train_data=None)

    Performs robust site correction by extracting the site random effects (re() terms) of every parameter of the fitted GAMLSS model and adjusting data to a reference site. Creates a new column ‘{y_val}_adjusted’ with site-corrected values while preserving all original data.

    How the values are moved depends on the model:

  • Site only in mu, identity link, location family (e.g. NO, SHASH, TF): each value is shifted by the difference between its site’s effect and the reference site’s effect. This is a plain shift.

  • Otherwise (site also in sigma, nu or tau, a log link, or a family where mu is not a location, e.g. GA): each value keeps its centile. A value on the 80th centile of its own site’s distribution moves to the 80th centile of the reference site’s distribution.

    If the model has no re() site term, a warning is given and nothing is adjusted.

    Parameters:

        train_data : pandas.DataFrame
            Original training data containing the site/group information

        reference_site : str
            Site to use as reference (all other sites adjusted to this baseline). It must be one of the model’s sites; any other value raises an error

        correction_col_name : str, default=’site’
            Name of the column containing site/group information for correction

        model_train_data : pandas.DataFrame, optional
            The data the model was fitted on. Only needed when train_data is other data than the model’s own training data and the adjustment is not a plain shift (the centile mapping needs the model’s predictions for those rows). plot_centiles(site_correction=True) passes it for you

    Returns:

        adjusted_data : pandas.DataFrame
            Same as input with additional ‘{y_val}_adjusted’ column containing site-corrected values


Examples:

# Site correction with custom column name
adjusted_data = gamlss_model.create_site_adjusted_data(
    train_data=train_data1, 
    reference_site='HJDXM',
    correction_col_name='site'
)

# The adjusted data will have both original and corrected y values
print(f"Original columns: {df_train.columns.tolist()}")
print(f"Adjusted columns: {adjusted_data.columns.tolist()}")
print(f"New column: {gamlss_model.y_val}_adjusted")
