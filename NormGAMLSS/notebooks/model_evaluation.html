gamlss_main.Gamlss.
evaluate#

evaluate(test_data, train_data, func_name=None, handle_outliers=True, affected=None,
         affected_col_name='affected', use_transfer=False, gam_refit_path=None,
         adjustment_covariates=None, params_to_adjust=None, treat_missing_as_healthy=False)

    Calculates six key evaluation metrics for assessing GAMLSS model quality:

  1. Z_Scores_Mean: Mean of normalized quantile residuals (z-scores) (should ≈ 0)

  2. Z_Scores_SD: Standard deviation of normalized quantile residuals (z-scores) (should ≈ 1)

  3. Logarithmic_Score: Mean log probability density (higher values indicate better fit)

  4. Skewness: Bias-corrected asymmetry measure (values close to 0 indicate symmetry)

  5. Kurtosis: Bias-corrected excess kurtosis (values close to 0 indicate appropriate tail behavior)

  6. Normality_Test_Statistic: Adaptive normality test (Shapiro-Wilk for n≤5000, Anderson-Darling for n>5000)

    Parameters:

        test_data : pandas.DataFrame
            DataFrame containing the test data for evaluation

        train_data : pandas.DataFrame
            DataFrame containing the training data used for model fitting

        func_name : str, optional
            Distribution family name. If None (default), the model’s own family is used; a different family raises an error

        handle_outliers : bool, default=True
            Whether to apply censoring for extreme values at 1st and 99th percentiles

        affected : array-like, optional
            Array indicating affected status for filtering to healthy subjects only.
            If None, attempts to use column specified by affected_col_name from test_data.
            If neither array nor column exists, assumes all subjects are healthy.
            Supports multiple formats:
            • 'None': the text 'None' is treated as healthy
            • Missing values: np.nan or None raise a ValueError, unless treat_missing_as_healthy=True
            • Binary masking: 0 = healthy, 1 (or non-zero) = affected
            • Healthy labels: the whole label is 'healthy', 'healthy control', 'healthy controls', 'control' or 'controls' (any case, e.g. 'Healthy', 'HEALTHY', 'Healthy Control')
              labels that mention ‘healthy’ or ‘control’ but are not on this list (e.g. 'healthy subject', 'HealthyControl', 'unhealthy') raise an error asking you to rename them; any other string (e.g. 'MDD') is treated as affected

        affected_col_name : str, default=’affected’
            Name of the column in test_data to use for identifying healthy subjects.
            Only used if affected parameter is None.
            Supports the same formats as the affected array ('None', binary, strings).

        use_transfer : bool, default=False
            If True, use site transfer adjustments for predictions and z-scores.
            Requires gam_refit_path to be provided.

        gam_refit_path : str, optional
            Path to saved adjustment model (.rds file).
            Required when use_transfer=True.
            Should be obtained from multisite_transfer() results.

        adjustment_covariates : list of str, optional
            Column names in test_data used as covariates in the adjustment model.
            Only needed if use_transfer=True and the transfer model was fitted with covariates.
            Required when the adjustment model has covariate terms; leaving it out then raises an error (default is None).

        params_to_adjust : list of str, optional
            Parameters the transfer adjusted (site_transfer’s params_to_adjust). Only used if use_transfer=True.
            If None (default), read from the saved adjustment model itself; if given, it must match what the transfer adjusted (an error is raised otherwise).

        treat_missing_as_healthy : bool, default=False
            Whether subjects with a missing status (np.nan or None) count as healthy.
            By default they raise a ValueError, because a missing diagnosis is not a healthy one. The text 'None' is always healthy, whatever this is set to.
            Note that pd.read_csv reads the text None as missing; read the file with pd.read_csv(..., keep_default_na=False, na_values=['']) to keep it.

    Returns:

        results_df : pandas.DataFrame
            DataFrame with two columns: ‘Metric’ and ‘Value’ containing six evaluation metrics


Examples:

# Example 1: Using binary masking (0 = healthy, 1 = affected)
affected_binary = np.array([0, 0, 1, 0, 1, 0, 0, 1])
results = model.evaluate(test_data, train_data, affected=affected_binary)

# Example 2: Using the text 'None' for healthy subjects
affected_none = np.array(['None', 'None', 'Disease A', 'None', 'Disease B', 'None'])
results = model.evaluate(test_data, train_data, affected=affected_none)
# 'None' → treated as healthy
# 'Disease A', 'Disease B' → treated as affected
# A missing status (np.nan or None) raises a ValueError; pass
# treat_missing_as_healthy=True only if missing really means healthy

# Example 3: Using healthy labels (whole label, case-insensitive)
affected_strings = np.array(['Healthy', 'Healthy Control', 'Affected',
                             'HEALTHY', 'MDD', 'controls'])
results = model.evaluate(test_data, train_data, affected=affected_strings)
# 'Healthy', 'Healthy Control', 'HEALTHY', 'controls' → treated as healthy
# 'Affected', 'MDD' → treated as affected
# Labels such as 'healthy subject', 'HealthyControl' or 'unhealthy' raise a
# ValueError: rename them to a healthy label (or 'None') or to a condition name

# Example 4: No affected parameter (all subjects assumed healthy)
results = model.evaluate(test_data, train_data)

Notes:

  • Evaluation is performed only on healthy subjects identified through the affected parameter

  • The method automatically filters out affected subjects before calculating metrics

  • The number of healthy subjects used is printed during execution

  • If no healthy subjects are found after filtering, a ValueError is raised

  • A missing status (np.nan or None) raises a ValueError, unless treat_missing_as_healthy=True

evaluate_ml(test_data, train_data, transform=True, verbose=False, affected=None,
            affected_col_name='affected', use_transfer=False, gam_refit_path=None,
            adjustment_covariates=None, params_to_adjust=None, treat_missing_as_healthy=False)

    Calculates six machine learning evaluation metrics for assessing predictive performance:

  1. MAE: Mean Absolute Error (lower values indicate better predictions)

  2. MSE: Mean Squared Error (lower values indicate better predictions)

  3. RMSE: Root Mean Squared Error (lower values indicate better predictions)

  4. R_Squared: Coefficient of determination (values closer to 1 indicate better fit)

  5. MAPE: Mean Absolute Percentage Error (lower percentages indicate better accuracy)

  6. Mean_Error: Prediction bias (values close to 0 indicate unbiased predictions)
